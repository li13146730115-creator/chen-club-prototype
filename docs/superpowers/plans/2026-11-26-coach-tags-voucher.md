# 私教、标签与预约凭证实现计划

**目标：** 在 4.30.0 上补充可维护、可发布、可预约的私教内容，闭环标签与推荐组件，并精简预约凭证。

**设计：** 商家后台 M26 私教管理含分类维护和课程编辑，M25 为标签管理；私教资料沿用员工与预约服务模型，新增课程同步价格、封面、介绍和可预约日期／时段。装修“健身私教”仍用两种既有版式，增加分类或多选私教的来源配置；更多页继承组件筛选。预约凭证采用暖棕品牌区、米白纸面和醒目日期／时间，保持二维码、状态与操作协议，规则及备注折叠。

**实现边界：** v21-coaches.js/css 负责私教资料、分类与会员列表详情；v21-coach-decoration.js/css 负责装修配置及拖动；v21-tags.js/css 负责标签 CRUD、商品选择与推荐读取；v21-voucher.js/css 仅改变预约凭证呈现。保留当前首页、权益、购物车、支付和商家代客链路。模块按店铺隔离，状态持久化，草稿与发布隔离。
