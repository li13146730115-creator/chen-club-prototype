# V0.10 Word 调整计划

依据：小程序调整- V0.10.docx，基线 d96326b（V4.23.0）。仅调整 8 组要求及必要关联功能。

1. 保留首页原有卡套和布局，弱化底线、添加低对比纹理；权益会籍卡同步纹理。
2. 扫描商品与服务价格展示，预约显示单次价格（包括 0 元）；未配置价格显示“查看详情”。不改客户原始价目。
3. 权益商品图增大并统一内边距；移除“已购”展示标签，保留已购资产与使用流程。
4. 手机预约选券支持数量，将数量带入原有报价、扣减与取消返还流程。
5. 运营入口进入首个可见模块首个页面，移除旧默认概览；会员等级价格迁移至商家商品/服务新增与编辑表单，原运营端不再提供写入。
6. 桌码配置：复用项目店铺及分类商家，菜单勾选商品、分类排序显隐和可选菜单价；一码绑定一个菜单、一个商家，二维码仅含项目/桌位/场景，重绑菜单不换码。
7. 扫码按桌码菜单展示；实体加购付款送桌，预约独立选日期时段、锁资源、预约付款核销。各订单记录项目、桌位、场景、类型，禁止混合结算；检查失效/跨项目菜单。
8. 先编写价格、数量、菜单与订单隔离测试，完成后跑全套回归；以 375×812 和 1440×900 进行页面与交互检查，复核改动范围，更新逐项记录、本地离线包和 GitHub Pages。

并行分工：v13-owner 负责移动端展示及选券；v13-merchant 负责会员等级价格；主任务负责桌码配置、菜单关联、默认入口及集成验收。
