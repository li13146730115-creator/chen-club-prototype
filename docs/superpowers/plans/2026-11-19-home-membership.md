# 首页会籍卡细节调整

**目标：** 根据用户截图的四项要求，调整首页会籍卡的位置、底部遮挡和会员码入口。

**设计：** 保留墨绿卡面、金色卡名和有效期。卡包整体排列在 Banner 下方，消除负间距。卡面两侧留白，底部遮挡延伸至 375 px 画布两侧；高度由 24～26 px 压缩为约 18 px，以两层浅曲线形成“云遮月”的掩映效果。卡名、有效期在左，右侧为独立的会员码按钮。

**实现边界：** 沿用 `A.v05.membership()` 共享组件，使首页、装修画布和会籍设置预览一致。卡面点击保留权益／卡包跳转；会员码按钮直接调用现有 `member-code`，游客继续进入登录认证。两个交互元素保持并列，避免按钮嵌套在链接内。
