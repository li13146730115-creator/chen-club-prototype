# 宸CLUB现有小程序与会议调整 Implementation Plan

> **For agentic workers:** 在当前会话内按任务实现并核验，不另行派发或等待批准。

**Goal:** 落实2026-11-18会议修改项，使首页、权益、服务、我的承接新UI，核心商品与交易页面依据现有小程序。

**Architecture:** 保留既有Club路由、业务状态和店铺隔离；增加v09权益呈现、商城交易及后台维护模块。规格、库存、购物车与订单快照共享同一模型，会员支付与员工收款区分。

**Tech Stack:** 原生HTML/CSS/JavaScript，Node VM流程测试。

**Spec:** 项目内meeting_01.mp4，客户已打开的宸CLUB小程序，以及JAVA-MER-V2.3_20260603/mer_uniapp现有源码。

## Global Constraints

- 移动端375×812，PC端1440×900；延续既有顶部和底部导航定位修复。
- 商品名称、权益规则和明确价格沿用客户资料；规格不任意增加加价。
- 核心交易使用现有白底圆角卡片、绿色主题、规格弹层、订单状态和收银台结构。
- 业主原型模拟支付，不请求真实支付接口；员工收款流程继续支持线上收款码和线下收款。
- 小程序展示的卡面、分类、规则、广告、商品规格及库存均有PC维护入口。
