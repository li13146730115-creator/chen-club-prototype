# V0.14 增量实现与验收计划

基线：4.28.2 / 9f054d8。需求源为《小程序调整- V0.14.docx》的六项文字与四张截图；仅调整这些项目及必要的关联流程。

## 设计与职责

1. 权益页保留业务和二级状态，分类 Tab 改为截图的三项块状导航。商家工作台补回工单处理第四入口，保留订单与扫码导航。
2. 活动新增和编辑使用本地图片上传、校验及预览；已上传图片与活动排期随保存同步至会员端。
3. 钱包按会所和会员记账。线下实收登记凭据后入账，不提供会员线上充值。默认只允许 SPA 商品分类；整单均在适用分类且余额足够方可储值支付，不与微信混合付款。其他商品不展示储值方式。支付后扣余额并沿用原商品库存、订单履约与退款逻辑；退款原路退钱包。
4. 邀请函只保留邀请人、活动名称、时间及位置，去掉重复服务/场地行、浏览器记录说明。
5. 推荐组件标签从本项目真实服务、商品及会员分类和标签中下拉勾选。商品/服务决定推荐内容，会员标签决定适用人群；不选会员标签默认全部。保留已有内容与发布流程。

新文件职责：v19-content.js/css（权益、工单、活动、邀请）；v19-tags.js/css（装修标签）；v19-wallet-model.js（账本、分类、支付及退款）；v19-wallet-ui.js/css（会员钱包、线下登记、规则和流水）。index.html 负责按依赖加载，版本更新4.29.0。

## 验证顺序

- 新行为先添加失败测试，再实现并通过；记录测试命令和结果。
- 钱包验证：会员/会所隔离、金额校验、凭据幂等、SPA与混单限制、余额不足、重复付款、库存失败无扣款、部分/整单退款及审核退款回流。
- UI 验证：权益双层 Tab、工单进入处理、活动上传保存和手机显示、邀请精简、推荐标签勾选/保存/发布、会员钱包与后台登记/查询。
- 浏览器分别按375×812与1440×900基准核验；保留截图和逐项结果。
- 全量 node --test tests/*.test.cjs；独立代码审查后修复必须项；检查 diff，发布并读取线上版本验证。
