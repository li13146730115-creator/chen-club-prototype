# 4.28.2 代客支付与会员页稳定性修复

用户要求：在线支付点击后弹出二维码；首次进入会员信息页不持续闪烁。

根因：旧 app.js 收到 storage 事件直接替换 S，各业务模块仍持有旧引用；进入代客页的初始化、扫码上下文清理再次写缓存，引发旧版和新版页面相互覆盖、反复重绘。实测新旧两页 1.2 秒内分别重绘21次、33次。整棵 DOM 替换可吞掉 pointerdown 与 pointerup 之间的 click。

- [x] 新增失败测试覆盖版本隔离、一次迁移、同步不回写、无扫码上下文不保存和在线二维码弹窗。
- [x] 使用 v2 缓存同步协议，首次读取旧 v1 数据，后续只读取 v2；保留旧缓存供旧页使用。
- [x] 接收同步时保留业务共享引用，渲染期间禁止再次写回；未变更时不写入。
- [x] R.clear 在无上下文时直接返回，消除普通页面无意义保存。
- [x] 代客在线方式主动弹出二维码，显式绘制，关闭后可重开，确认支付仍走同一订单状态约束。
- [x] 所有回归443项通过，新旧标签共存下会员输入、支付弹窗及当前版本同步实测通过。
- [ ] 关联各端预约支付复核，代码审查与 GitHub Pages 发布验证。
