# 品宣字体调整实现计划

**目标：** 参考客户发布会 PPT 的楷书标题、较轻说明文字及疏朗字距，调整原型字体。

**资料结论：** 原 PPT 共 33 页，内容均为整页位图，无实际文字运行或内嵌字体。主题中 Helvetica / Helvetica Neue 是模板设置，不能据此认定画面中的中文字体。第 1、2、3、5、8、16、28、33 页可见楷书笔意。采用霞鹜文楷 Regular 作为网页上的近似表达，不宣称为品宣原字体。

**架构：** 新增末尾加载的纯 CSS 字体层。品牌标题使用随包保存的 WOFF2；正文采用 Helvetica Neue / 苹方 / 微软雅黑回退，数字采用易读的等宽数字特性。保留 AI 字形 SVG、色彩、结构、尺寸和全部业务 JS。

**技术栈：** 原生 HTML、CSS，Node 测试，fontTools 转换字体，CUA 浏览器核验。

## 文件

- `assets/fonts/`：本地文楷 WOFF2、OFL 许可证、来源及字体元数据。
- `v23-typography.css`：标题、正文、金额、表单及装修预览的字体覆盖；不改宽高、间距、图片或业务数据。
- `index.html`：最后加载字体样式并预加载常用字集，升级缓存版本。
- `tests/v23-typography.test.cjs`：离线资源完整性、许可证、字体覆盖及纯视觉边界检查。
- `docs/qa/v4.33.0/README.md`：来源事实、核验结果及限制。

## 验收边界

只修改字体家族、字重、标题字距和数字排版，不修改字号、行高或组件尺寸。字体加载失败时立即显示系统楷体/宋体回退，不阻塞操作。字体资源随原型保存，离线打开不依赖第三方 CDN。
