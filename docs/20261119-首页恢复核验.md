# 首页恢复核验 · V4.22.1

本次按用户要求恢复 V4.21.0（6befead）的首页外观。V0.9 的会籍、商品、卡券、反馈及代客业务调整继续保留。

问题原因：新装修渲染器直接解释旧样式编号。未发布过装修的首页创建会籍组件时使用样式 0，因而被新渲染器错误显示为浅色横卡；浅色横卡又继承了旧卡套的固定高度、边框，形成截图中的大块嵌套卡片。内容、私教和部分轮播样式也存在旧配置被重新解释的问题。

修复：旧配置沿用上一版的组件渲染与样式；仅在后台主动选择新样式时记录版本标记并应用新布局。旧轮播样式 2 不再被强制改成样式 1。横卡的固定高度、边框已清理。后台会籍样式选中态与实际卡套保持一致。

| 核验项 | 结果 |
| --- | --- |
| 首页会籍 | 深绿卡面，仅卡名与有效期；右侧会员码入口保留 |
| 云层 | 底部三层波形遮挡，宽 375px、高 18px，延伸到屏幕两端 |
| Banner | 保留 60% 基准，高 487.2px；会籍卡位于 Banner 下方 |
| 近期预约与今日可约 | 保留左侧服务名称、右侧日期时间及原双列服务卡 |
| 会所生活、康养、私教及其他组件 | 旧配置沿用上一版结构、正文和布局 |
| 首次访问、旧发布快照、旧草稿 | 覆盖三会所及旧样式 0/1；另核验轮播样式 0/1/2 |
| 前后台一致 | 1440×900 装修台与草稿预览共享恢复后的渲染器 |
| 交互 | 项目下拉切换、轮播切换、会员码、装修样式切换与预览均可用 |

浏览器在同一份本地保存状态下加载上一版首页与恢复版，比对 Banner、卡套、云层、预约、今日可约、内容及私教组件的尺寸和位置，结果一致。截图和布局读数见 [V4.22.1 验收资料](qa/v4.22.1)。

验证命令：`node --test tests/*.test.cjs`，248 项通过、0 项失败；`git diff --check` 通过。新增回归测试已先复现首次访问缺少云层及旧轮播样式被覆盖的问题，再验证修复。
