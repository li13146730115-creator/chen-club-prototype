# 商家商品添加／编辑页核验 · 4.32.0

基线：4.31.0 / ed33b37。调整范围为 M11 商品添加／编辑页及其页签、规格、图片维护交互。

## 原商城参考依据

- 用户提供 `https://club.c-land.com/crmeb/product/list`。本次访问跳转手机号、短信验证码登录页，未在真实商城创建或修改商品。
- 使用项目内原商城 `JAVA-MER-V2.3_20260603/mer_mer_admin/src/views/product/creatProduct/index.vue` 和 `src/mixins/product.js`：原实体商品表单四页签“商品信息、规格库存、商品详情、其他设置”，108px 标签栏、白色卡片、32px 输入控件、方形上传区和前后步骤操作。
- 保留当前宸CLUB暖棕主题及双层后台导航。当前未建模的平台分类、品牌、运费模板等目录未虚构；原型已有的商品、标签、会员价和次卡保存链继续使用。

| 检查项 | 结果 |
| --- | --- |
| 商品信息 | 名称、店铺分类、单位、关键字、简介、标签、主图和轮播图在同一页签维护；单位、关键字、简介保存后持久回显 |
| 图片区 | 主图及规格图使用方形预览，本地文件可更换；轮播图支持多张上传、移除，最多10张，单图2MB以内；校验格式及读取错误 |
| 规格库存 | 规格名称、售价、库存、规格图及删除同表维护；新增保留原规格与会员价；至少保留一条规格 |
| 会员价 | 复用既有按会籍、成人儿童及规格的会员价矩阵；空白沿用原价，填0表示免费；保存仍用于原报价 |
| 商品详情 | 独立页签维护现有商品详情文本；未填写时保存定位该页签并显示错误 |
| 其他设置 | 配送方式、商品状态、次卡关联及使用设置；普通商品隐藏次卡配置，关联本店服务后展开 |
| 草稿 | 切换页签、增删规格、上传图片和选择次卡服务后，名称、标签、轮播图、会员价及其它已填内容保留 |
| 保存返回 | 添加后回到M05列表；重新编辑及刷新，2条规格、售价500/560、会员价400、2张轮播图、5次/90天的本地测试数据回显一致 |
| 店铺隔离 | 切换会所或打开另一商品重回商品信息页；禁止编辑其它店铺商品 |
| 页面布局 | 浏览器1440×900，主图80px方形、规格图56px方形；信息、规格、详情、其他设置逐页检查，无横向溢出；保存按钮在底部操作区 |
