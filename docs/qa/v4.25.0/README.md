## 关联流程复核

- 扫码桌位/会所/菜单价格及购物车隔离；类别下架后旧清单无法绕过校验。单SKU加减、多SKU弹层与库存校验。
- 人数按同时占用计算；不重叠时段不累加。容量开关仅控制展示，隐藏人数后仍校验超额。拒绝0、负数及小数人数；批量预约先校验、后保存。
- 活动详情保留普通文章分支；活动改为普通内容后不继续出现在月历。固定活动排期不可任意改期；普通服务改期保留。
- 从扫码菜单进入活动月历/预约时清理当前桌位上下文，保存原扫码购物车。实际浏览器完成了活动选择→预约→确认→零元演示下单→凭证→分享预览。
- 邀请函只包含赴约公开信息；过期、取消与不同会所订单受限。同一浏览器可显示本地状态，其他浏览器使用邀请快照。

## 原型演示边界

泳池20人为可配置的演示容量，具体饱和人数由会所确认。活动为演示排期，地址中的“位置待会所核实”应替换为会所正式地址。

邀请函通过浏览器链接/系统分享完成演示；微信原生转发、微信昵称授权及跨浏览器实时预约状态需正式接口联调。邀请快照仅用于分享赴约信息，不作为核销凭证。
