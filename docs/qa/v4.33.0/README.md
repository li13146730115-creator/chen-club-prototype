## 品宣参考与字库

客户提供的《宸园139发布会吴总ppt0717.pptx》共33页，全部为整页位图，无可提取的文字运行或内嵌字体。主题中的 Helvetica / Helvetica Neue 不能证明画面中的中文字体。目视核对第1、2、3、5、8、16、28、33页，标题具有楷书笔意，说明文字较轻、字距疏朗。

网页采用霞鹜文楷 Regular 作为视觉近似，不宣称为PPT原字体。来源为[官方仓库](https://github.com/lxgw/LxgwWenKai)，版本1.530，上游提交、文件SHA256及字符范围记录在 [source.json](../../../assets/fonts/source.json)，许可保存在 [OFL.txt](../../../assets/fonts/OFL.txt)。仅对子集及格式转换，未编辑字形轮廓。

- 常用字集：276,200字节，包含原型现有文本使用的1,471个字符，首屏预加载。
- 扩展字集：7,807,076字节，包含其余45,455个字符，按 Unicode 范围需要时加载，保留后续装修文案的覆盖。
- 两份WOFF2随原型保存，不依赖字体CDN；使用 `font-display:swap`，失败时回退系统楷体或宋体。
