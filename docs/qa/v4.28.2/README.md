# 4.28.2 会员页闪烁与支付二维码核验

2026-11-25。

修复项目：

1. 在线支付直接弹出“会员扫码支付”二维码对话框，显示本单金额；可关闭并重新打开。
2. 隔离仍打开的旧版页面缓存，首次升级保留原订单、会员及运营配置；新版页面接收同步时不再回写，引发循环的无效扫码上下文清理不再保存。
3. 重置演示数据入口使用当前缓存协议，普通会员自助微信收银台保留。

证据：

- 修复前：用旧 app.js 与当前代码两页共存，在1.2秒内分别重绘33次和21次；按钮在按下与松开期间被替换，浏览器不再派发 click。

- `node scripts/verify-proxy-stability.cjs`：保留一个真实旧版同步实现标签页。新页首访、S03/S10/A27/M17会员信息输入稳定；旧页回写不会覆盖姓名和草稿；延长点击后二维码正常弹出、可关闭重开、支付进入完成状态。
- 同版本两标签页仍可同步业务状态，接收页缓存写入数不增加，闲置时不重绘。
- 同一订单被其他标签切换支付方式后，PC旧扫码弹窗立即关闭；旧在线确认操作也会校验方式，避免按线下记账。
