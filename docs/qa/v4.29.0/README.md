## 钱包演示口径

- 默认仅勾选 SPA 商品分类。整单全部商品符合当前会所规则且余额足够时，可使用钱包全额支付，不与微信混合扣款。预约服务不适用此商品钱包规则。
- 北京宸园新增 8 项护理演示商品，价格来自客户 SPA 价目：498、658、498、248、720、1180、1980、1980 元。未把北京报价复制到其他项目。
- 北京首位会员有 5 笔明确标注为演示的线下储值记录，合计 3,000 元。其余会员余额从 0 起，由线下登记入账；这些余额不是客户真实资产。
- 钱包账本按会所和会员记录，不随会员归属转移。有储值流水的会员转店时提示在新会所独立建档；历史已转店记录仍按原订单归还原账户，账户异常在退款变更前拒绝。
- 支付与退款沿用原库存、订单、核销与售后能力。全部为本地原型模拟。
