## 数据与实现边界

北京、紫京私教示例继承原店铺健身教练，每店五条，默认价格读取原健身私教报价；第三会所未确认课程不补造价格。商家新增课程按维护价格独立报价。资料、标签、商品及装修快照按店铺隔离，持久保存在原型的浏览器本地存储中。预约、付款和核销仍为同一套演示业务模型。
