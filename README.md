商品详情、规格、购物车、确认订单、微信收银台结构及订单状态参考现有商城；支持到店核销、配置支持的快递配送、发货收货、退款及未履约权益恢复。支付、核销、退款防重复处理，已使用购买次卡不能直接撤销购买。
