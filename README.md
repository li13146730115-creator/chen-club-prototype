移动端375×812px，首页Banner保留60%基准；PC端1440×900px，沿用客户商城后台的蓝色控件、表格和导航。首页、权益、服务、我的保留墨绿金色；内部交易页参考现有小程序的绿色、灰底白卡、规格弹层和底部操作栏。

商品支持规格图片、价格、库存、数量、加购、勾选结算；北京客户茶水单提供五种真实茶品及价格用于多规格演示。普通商品是否配送由商家配置，次卡购买后生成权益。业主使用微信收银台结构，原型仅模拟支付；员工代客保留线上收款码和现场收款。订单、规格和支付记录供各端共同查询。

核心入口：U03权益、U05服务、U12我的、U33商品详情、U29购物车、U22确认订单、U23收银台、U24全部订单；A29权益卡配置、A32/M12权益及服务装修、M11商品及规格配置、A08/M07订单管理。

验证命令：`node --test tests/*.test.cjs`。本版142项检查通过；浏览器核验移动375×812和PC1440×900，覆盖商品规格、下单支付、权益卡及维护入口。实机已观察小程序首页、预约页、商品详情、购物车、确认订单及订单列表，其他交易页依据本地商城源码对照，逐页实机视觉复核范围见核验记录。
